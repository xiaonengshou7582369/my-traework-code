这份代码是怎么来到 GitHub 的？

  1. 在 GitHub 创建仓库 my-traework-code
  2. 用 git clone 把仓库克隆到本地
  3. AI 在本地生成 index.html 和 style.css
  4. git add . 暂存所有变更
  5. git commit -m "..." 提交到本地历史
  6. git push 推送到 GitHub

以后每次开发完，重复 add → commit → push 三步即可 ✅
